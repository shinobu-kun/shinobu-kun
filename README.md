# 馬場 偲(ばば しのぶ)

自宅葬の普及と、地域の弔い文化の再構築にまいります。
株式会社鎌倉自宅葬儀社 代表取締役。

---

## 🏠 活動・仕事

- 自宅葬の施行・相談対応(現場経験20年以上)
- 自宅葬の啓蒙コンテンツ発信(note・SNS)
- 葬儀費用の透明化・セカンドオピニオン葬儀社としての情報提供
- 自力葬サービスの設計・マニュアル制作

## 💡 目指していること

葬儀を「業者に任せるもの」から「家族が主体的に選ぶもの」へ。
鎌倉を拠点に、人を想う文化を地域から再構築しています。
